# Пошаговая инструкция: Публикация веб-приложения на GitHub Pages

Это веб-приложение создано специально для работы на **любых смартфонах (iPhone / iOS Safari, Android)** и компьютерах прямо через браузер с поддержкой работы офлайн (PWA).

---

## Вариант 1: Загрузка через браузер на GitHub.com (Самый простой способ)

1. Откройте [GitHub.com](https://github.com/) и войдите в свой аккаунт.
2. Нажмите зеленый значок **«New»** (Создать новый репозиторий).
3. Укажите название репозитория, например: `camdatam` (или `camdatam-web`).
4. Выберите **Public** (Публичный) и нажмите **«Create repository»**.
5. На странице созданного репозитория нажмите **«uploading an existing file»** (загрузить файлы).
6. Перетащите все файлы из папки `D:\CamDataM\WebApp\`:
   - `index.html`
   - `app.js`
   - `vision.js`
   - `manifest.json`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
7. Нажмите зеленую кнопку **«Commit changes»** внизу.

## Вариант 2: Загрузка через консоль (Git)

В папке `D:\CamDataM\WebApp`:
```bash
git init
git add .
git commit -m "Initial commit for CamDataM PWA"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/camdatam.git
git push -u origin main
```

---

## Включение GitHub Pages (1 клик):

1. В репозитории на GitHub перейдите во вкладку **Settings** (Настройки) сверху справа.
2. В левом меню выберите пункт **Pages**.
3. В блоке **Build and deployment**:
   - **Source:** выберите `Deploy from a branch`
   - **Branch:** выберите `main` (или `master`) и папку `/(root)`
   - Нажмите кнопку **Save** (Сохранить).
4. Подождите 30-60 секунд и обновите страницу.
5. Вверху появится готовая ссылка на сайт вида:
   **`https://ваш-логин.github.io/camdatam/`**

---

## Как запустить и закрепить на iPhone (Safari):

1. Откройте полученную ссылку в браузере **Safari** на iPhone.
2. Разрешите доступ к камере при запросе.
3. Внизу экрана Safari нажмите центральную кнопку **«Поделиться»** (квадрат со стрелкой вверх).
4. Прокрутите вниз и выберите **«На экран "Домой"»** (Add to Home Screen).
5. Нажмите **«Добавить»**.

🎉 **Готово!** На рабочем столе iPhone появится иконка приложения. Оно запускается на весь экран, без рамок браузера, и работает мгновенно даже без подключения к интернету!
